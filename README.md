## Layout

Directories follow the flow of the work, from inputs to figures.

- `data/raw/` Input data, never modified by code.
- `data/processed/` Derived data, reproducible from `data/raw/` and the code.
- `src/analysis/` Reusable Python code imported by the notebooks.
- `tests/` Tests for `src/analysis/`.
- `notebooks/` Jupyter notebooks, numbered in the order they should run (`01-...`, `02-...`).
- `figures/` Figures generated by the notebooks.
- `pyproject.toml` Project metadata, dependencies, and ruff/pytest settings.
- `uv.lock` Exact versions of all dependencies, for reproducibility.
- `.zenodo.json` Metadata for Zenodo. `CITATION.cff` Citation metadata for GitHub.
- `AGENTS.md` Instructions for AI coding assistants (`.claude/CLAUDE.md` links to it).

## Requirements

To run on your own computer, install [uv](https://docs.astral.sh/uv/) and run

``` bash
uv sync
uv run jupyter lab
```

`uv` installs the Python version in `.python-version` and the exact package versions in `uv.lock`.

## Development

``` bash
uv add scipy                # add a dependency (updates pyproject.toml and uv.lock)
uv run pytest               # run tests
uv run ruff check --fix     # lint Python and notebooks
uv run ruff format          # format Python and notebooks
```

CI runs these checks on every push and also validates `.zenodo.json`.

## Checklist - delete before publishing

- [ ] Add authors incl. ORCIDs and other relevant metadata to `.zenodo.json` and `CITATION.cff`; to learn more about the available datafields, see
  [here](https://developers.zenodo.org/?python#depositions). Add funding under `grants` if applicable.
  CI validates `.zenodo.json`; to check it locally:
  ``` bash
  uvx check-jsonschema --schemafile https://raw.githubusercontent.com/zenodo/zenodo/master/zenodo/modules/deposit/jsonschemas/deposits/records/legacyrecord.json .zenodo.json
  ```
- [ ] Set `name` and `description` in `pyproject.toml`; rename `src/analysis/` if you like.
- [ ] Add the DOI of the associated publication to `.zenodo.json` (`related_identifiers`) and `CITATION.cff`.
- [ ] Add dependencies with `uv add`.
- [ ] Describe the data in `data/raw/`: origin, format, units.
- [ ] Check that every notebook runs from a clean checkout, in order.
- [ ] If needed, change the license (`LICENSE`, `pyproject.toml`, `.zenodo.json`, `CITATION.cff` and the badge in `README.md`), see _e.g._ [Creative Commons alternatives](https://github.com/santisoler/cc-licenses).
- [ ] Activate GitHub tracking of the repository on https://zenodo.org. Repository must be public.
- [ ] Create a release on GitHub - adhere to [SemVer](https://semver.org). This triggers a deposition on Zenodo.
- [ ] Once you get the Zenodo DOI, add a badge to the top of this README. Use the link to _all_ versions.
- [ ] Feel free to update and make new releases!
